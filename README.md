# Rutas a Pie 1.7.0

Aplicación Android gratuita con 400 rutas, búsqueda, favoritos, GPS, grabación de caminatas e importación y exportación GPX.

Este repositorio compila automáticamente una APK de prueba mediante GitHub Actions. Las fichas son orientativas: confirma siempre accesos, permisos, cierres, meteorología y estado del recorrido antes de salir.
